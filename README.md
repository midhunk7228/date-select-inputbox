# date-select-inputbox

Custom inline date input that keeps the text-box look while providing smooth segment-based editing.

## Getting started

1. Open `index.html` in any modern browser.
2. Click the date to focus it. Use digits to replace the highlighted segment, ← → to switch segments, and ↑ ↓ to increment or decrement the active part.

The component never opens a calendar popover and keeps the exact single-field UI. It handles month-length adjustments, wraps values when using the arrows, and offers subtle animations for a polished feel.
